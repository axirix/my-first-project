# FinTrac

Personal finance tracker built with HTML, CSS and JavaScript.

**Demo:** https://axirix.github.io/my-first-project/

---

## About

FinTrac helps track personal income and expenses.

- Add income and expenses
- View balance by month
- Use categories: food, transport, education, and more
- Switch language: Russian, Kazakh, English, Turkish
- Data is saved in the browser

---

## How to run

1. Download the repository
2. Open `index.html` in any browser
3. No installation required

---

## Tech stack

- HTML5
- CSS3
- JavaScript
- LocalStorage
