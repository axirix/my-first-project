# 💰 FinTrac

A modern personal finance tracker.

## 🚀 About

FinTrac is a personal finance application that helps users:

- 💰 Track income and expenses
- 📊 Analyze spending
- 🎯 Save money for goals
- 🏆 Earn achievements
- 🤖 Get AI financial tips
- 🌍 Support multiple languages

## 🌍 Languages

- 🇷🇺 Russian
- 🇰🇿 Kazakh
- 🇬🇧 English
- 🇹🇷 Turkish
